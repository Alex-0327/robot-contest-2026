# 比赛当天现场调试 SOP

给全体队员看的版本，不需要懂代码，按顺序照做即可。
技术细节见根目录 `SOP.md`（开机激活）和 `操作注意事项.md`（踩坑汇总）。

## 一、开机顺序（错了会连不上）

1. **检查接线**（全部断电状态下）：
   - 手指轻拽灵巧手 CANFD 端子，确认不松（虚接 = 手完全无响应）
   - 电脑 ↔ 控制柜网线插紧
   - **急停按钮确认是旋出状态**（按下去 = 控制柜闪一下就灭）
2. **控制柜上电** → 灯环变色循环 = 自检中（1~2 分钟）→ **绿色常亮 = 就绪**，没绿不要往下走
3. **灵巧手上电**（能听到掌内风扇声 = 已供电，此手无指示灯，属正常）
4. **开 Linux 电脑**

## 二、软件自检

```bash
conda activate robot
cd ~/robot-contest-2026
PYTHONPATH=~/fairino-python-sdk/linux/fairino python src/check_all.py
```

看到臂位姿 + 手关节反馈、无错误码 = 链路全通。报错先看「五、应急处理」。

## 三、完整流程试跑一次

完整跑一次画龙点睛全流程（按主程序脚本的正常用法）。

- **没有偏差** → 直接等比赛，不要手痒改航点
- **有偏差** → 记下是哪个航点偏了（比如 `eye_dot` 点歪了），进入第四节微调

## 四、某个航点偏了：微调流程（核心）

原理：让臂自己走到那个航点 → 网页上按按钮一格一格挪 → 对准后一键覆盖保存。

1. 先退出其他占着机械臂的程序（示教守护进程：`echo quit > /tmp/teach_cmd`；
   控制器同一时刻只认一个程序）
2. 启动微调面板（在 Linux 机上）：

   ```bash
   PYTHONPATH=~/fairino-python-sdk/linux/fairino python src/jog_server.py
   ```

   浏览器打开 `http://localhost:8080`（从别的电脑访问需 SSH 转发：
   `ssh -L 8080:127.0.0.1:8080 user@linux机`）
3. 页面顶部下拉框**选中偏了的航点**，点「**去该航点**」
   ——臂会先原地抬高 → 平移 → 降下（高空过渡，不会横扫桌面），到位后提示可以微调
4. 用 X/Y/Z 按钮点动微调（键盘：←→=X，↑↓=Y，PgUp/PgDn=Z）；
   步长先用 5mm 粗调，接近后切 1mm 精调；姿态歪了用 RX/RY/RZ
5. 对准后点「**覆盖保存到该航点**」，弹窗确认
   ——会同时保存位姿和 6 个关节角（新格式），下次直接复现同一构型
6. **验证**：点别的航点走过去，再点回刚改的航点，看是否到位；不放心就重跑一次完整流程
7. 每个有偏差的航点重复 3~6

注意事项：

- **改航点前先备份**：`cp src/waypoints.json src/waypoints.json.bak`
- 旧格式航点（下拉框里标了「（旧格式）」）覆盖保存一次就自动升级成新格式
- 面板上一切报错，先点「复位+自动模式」再重试；还不行看第五节

## 五、断电顺序（收工 / 中午离场）

1. 确认所有运动脚本已跑完、面板已关（Ctrl+C）
2. 关控制柜电源（臂有关节抱闸，断电自锁不会塌）
3. 关灵巧手供电
4. 关电脑

## 六、应急处理

### 碰撞停机（err=186 = 运动中碰撞停止）

1. 先确认臂和周围东西都没坏，把臂周围清空
2. 面板上点「**复位+自动模式**」（碰撞后控制器锁存停止态，不复位的话后续
   运动指令会沉默失败——返回成功但臂不动）
3. 复位后还动不了 → **重启控制柜**（断电等 10 秒再上电，等绿灯）。
   重启后必查三件事：
   - 激活的工具坐标系会重置回 0 → 在 WebApp 上改回 1 号工具（或告知程序组）
   - CNDE 状态流要等几秒才起来
   - 重跑 `check_all.py` 确认链路全通，再继续

### 强杀进程后连不上（CNDE 占用）

控制器的状态流（CNDE）只支持单连接，且释放有约 12 秒延迟。
**Ctrl+C 或 kill 掉任何连着臂的 Python 进程后，等 12 秒以上再启动新程序**，
否则会报状态流相关错误。等完还连不上 → 重启控制柜。

### 错误码速查

| 错误码 | 含义 | 处理 |
|---|---|---|
| err=14 | 有未复位报警 | 先复位，别排查别的 |
| err=99/112 | 经过奇异点 | 已内建 move_ik 规避；仍出现就换条路 |
| err=123 | 关拖动后立刻切模式 | 等 1 秒重试 |
| err=154 | 工具坐标系不符 | 控制柜上改回 1 号工具 |
| err=185 | 超工作空间 | 目标点太远，检查航点数值 |
| err=186 | 运动中碰撞停止 | 见上面「碰撞停机」 |

### 其他常见现象

| 现象 | 原因 | 处理 |
|---|---|---|
| 控制柜闪灯即灭 | 急停被按下 | 旋出急停，重新上电 |
| 手完全无响应 | CANFD 端子虚接 | 断电后重新压紧端子 |
| 网页打不开 | 面板没启动 / SSH 转发断了 | 回 Linux 机看面板进程，重连 SSH |
| 去航点报错「逆解失败」 | 航点不可达（臂被挪动过？） | 先拍照记录，通知程序组，不要硬试 |
