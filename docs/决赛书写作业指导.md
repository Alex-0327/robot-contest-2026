## 1. 五步走

### 第 1 步：笔画取下来（只需联网一次，赛前做）

```bash
python src/stroke_lib.py --fetch 一去二三里烟村四五家亭台六七座八九十枝花
```

期望输出：`抓取完成，仍缺字：无`，并且每个字的笔数都对得上字帖（一=1 笔、去=5 笔、二=2 笔、
里=7 笔、家=10 笔）。全诗合计 **105 笔**，缓存里能看到。

> 现场机器不需要装任何中文字体、也不需要网络：`data/strokes_cache.json` 已带 20 个字。
> 万一要写别的字，`--offline` 之外的模式会用本地字体提骨架兜底，字形会散一些，先预览确认。

### 第 2 步：示教 5 个航点（`teach_waypoints.py`，握笔状态下拖）

| 航点 | 怎么放 | 说明 |
|---|---|---|
| `paper_a` | **笔尖点**在目标 A3 纸的**左上角**（纸边缘即可） | 三点必须同一张纸 |
| `paper_b` | 笔尖点在**右上角** | 决定纸的 x 方向 |
| `paper_c` | 笔尖点在**左下角** | 决定纸的 y 方向 |
| `ink_hover` | 笔尖离墨面约 20mm | 蘸墨前的待机点 |
| `ink_dip` | 笔尖刚触到墨面 | 蘸墨点 |

三个纸角点用**同一个写字姿态**去点（姿态取自 `paper_a`，后面所有字都用它）。
点歪了的判断依据：程序会打印 `tilt_deg`（纸面倾角，>3° 报警）和 `square_err_deg`
（三点是否互相垂直，>4° 报警）。

### 第 3 步：预演看效果（不接硬件）

```bash
python src/preview_poem.py            # 出图 out/preview_xxx.png + 工时估算
python src/preview_poem.py --chars 5  # 只看 5 字版本
```

看图确认三件事：字像不像楷体、有没有超出田字格（超出=0 分）、预估工时够不够。
文字笔顺号（红字小标）会画在起笔点上，可以直接核对笔顺。

### 第 4 步：干跑（算位姿，不动机械臂）

```bash
PYTHONPATH=~/fairino-python-sdk/linux/fairino python src/demo_write_poem.py --dry-run
```

会打印：每个字的目标格、base 坐标、距臂基座距离（可达性告警）、工时估算。
**先看工时**：`预估工时 xxxs`，和 255s（300s − 45s 熔断）比。

### 第 5 步：真机

```bash
PYTHONPATH=~/fairino-python-sdk/linux/fairino python src/demo_write_poem.py
```

流程：读航点 → 建纸面坐标系 → 打印可达性 → **等你按回车确认** → 先蘸墨 →
逐字写（写前查时间、查控制器报警）→ 收尾抬笔 → 打印写了几个字。

安全兜底：
- 每写一个字后查 `main_code`，有报警立即停
- 剩余时间 < `guard_s`（默认 45s）就不再起新字，抬笔收尾
- 任何异常都会先抬笔 80mm 再退出，不会把笔停在纸上

## 2. 现场要调的参数（都在 `data/write_plan.json`）

| 参数 | 默认 | 什么时候改 |
|---|---|---|
| `poem` | 前 10 字 | 工时不够就砍到 7 字 / 5 字（`--chars N` 也能临时砍） |
| `sheet` / `row` / `col_start` | backL / 2 / 1 | 换纸、换起始格 |
| `layout` | `a3_scaled` | ★打印后量一格：76.9mm 保持默认，54.4mm 改 `a4_raw` |
| `motion.write_vel` | 15 mm/s | 墨太淡/断笔就降到 10~12；写不完提到 18（>20 会甩墨） |
| `motion.clearance_mm` | 8 mm | 笔画抬笔高度：蹭到字就提到 12，时间紧可降到 6 |
| `motion.press_mm` | 0.3 mm | 下压量：墨淡 → 0.5；纸面晕染成团 → 0.1 |
| `dip.every_strokes` | 12 | ★**必须实测**：一次蘸墨能连续写多少笔/多少 mm |
| `dip.dip_cost_s` | 9 s | 实测一次蘸墨往返的实际秒数 |
| `guard_s` | 45 s | 保险余量（收尾 + 设备复原要留时间） |

### 蘸墨间隔怎么实测

1. 把 `dip.every_strokes` 改成 999，`pre_dip` 保持 true。
2. 写 5 个字，肉眼记录第几笔开始笔画变虚/发枯。
3. `every_strokes` = 那个笔数 × 0.8（留余量）；或者数一下用掉的墨长（`demo` 会打印累计 mm）。

## 3. 工时账（10-11 估算，务必自己复算一遍）

| 字数 | 笔数 | 预估工时 | 结论 |
|---|---|---|---|
| 5 | 18 | ~95s | 非常稳，第一次真机试就用它 |
| 7 | 35 | ~162s | 稳，余量 93s，推荐正式比赛用这个 |
| 10 | 54 | ~241s | 只剩 14s 余量，设备状态好才冲（能多拿 5 分质量分 + 1 组连续奖励） |

构成（10 字）：走笔 121s + 落抬笔 58s + 空移 25s + 蘸墨 4 次 36s。
**落抬笔和蘸墨占了 1/3**：抬笔高度从 15mm 降到 8mm 就省下 20s；蘸墨少一次省 9s。

## 4. 避坑（这几条都是本赛项特有的）

1. **一个字一格，超出田字格边框该字记 0 分**。笔画坐标按"占格 80%"缩放，实测 20 个字里
   最挤的"家"距格线还有 **6.8mm**（加笔宽也在格内）。不要为了好看去调 `GLYPH_FILL`
   （在 `stroke_lib.py` 顶部，调完要把 `CACHE_VERSION` 也 +1 并重建缓存）。
2. **翻腕姿态下笛卡尔 MoveL 可能报 err=99/112**。执行层已经内建兜底（自动退到逆解 MoveJ），
   日志里看到 `[write] MoveL err=... 改走逆解 MoveJ` 属正常，不是故障。
3. **写字期间手不能动**。本层不碰灵巧手（只有蘸墨后 `hand.check()` 读一次状态），
   千万不要在写的过程中去调手——松了就前功尽弃。
4. **纸必须压住**：移位 >10mm 扣 15 分。用镇纸压机械臂轨迹不经过的两条边。
5. **时间到就停**：不要把 `guard_s` 调成 0。超时 -50 分且超时部分不计分。
6. **连续 5 字奖励**：同一排 5 格写满才算"连续诗词内容"，所以**从 r2c1 开始按顺序写**，
   不要跳格。跨排会断连续（前 5 字仍然有效，后 5 字重新起算）。

## 5. `src/write_engine.py`：描红写字引擎（执行入口）

航点命名按现场采集规则走：**`paper{1-4}_{tl,tr,bl,br}`**，外加每页两个标定
`paper{i}_cell00_tl`（第 0 个田字格的**左上小格中心**）/`paper{i}_cell00_corner_tr`
（该田字格的**右上角**）。

```bash
python src/write_engine.py --char 日月山水火田 --sheet 1 --row 2 --col 1   # 默认只读，先审方案
python src/write_engine.py --list-cells                                    # 打印全部格心
PYTHONPATH=... python src/write_engine.py --char 日 --sheet 1 --row 1 --col 1 --execute
```

它做的事：
1. 每张纸用 tl/tr/bl 建局部坐标系，**第 4 角做校验**（>5mm 直接报错，不会带着歪坐标系写）
2. 格距优先用标定航点实算（两种语义都试一遍，取与图纸最接近的那个并打印用了哪种），
   没有标定航点就用官方图纸实测值兜底并**大声提示**
3. 输入"字 + 格号" → 输出一串 base 位姿（纯函数 `plan_char`，可以离线审）
4. 执行：进字抬 5cm → 平移 → move_ik 下降落笔 → 笔画 vel=3 → 抬笔 5mm 换下一笔
   （远距离笔画自动抬到 5cm 再平移，严格遵守"三段式"）
5. 每个字开写前 `reset_errors + set_mode(False) + enable(True)`，并查 `main_code`；
   MoveL 撞奇异点(99/112)自动转 move_ik，两个都失败才抛 `RuntimeError`

当前只放开**单体字白名单**（日月山水火田…45 个），多部件字要写就传 `allow_complex=True`
（或 `--allow-complex`），且**先离线看一遍 `plan_char` 的字形**再上机。
