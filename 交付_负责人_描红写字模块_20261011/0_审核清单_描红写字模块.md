## 三、5 分钟自检（不用接机械臂）

```bash
# 1) 出方案（只读，打印每笔的起终点坐标和长度）
python src/write_engine.py --char 日 --sheet 1 --row 1 --col 1 \
       --waypoints src/waypoints.json

# 2) 打印全部格心 base 坐标，核对格子落点
python src/write_engine.py --list-cells --waypoints src/waypoints.json --char ""
```

期望看到：`paper1: {...corner_err_mm: x.x...}` 每张纸的第 4 角误差（>5mm 会直接报错）、
`标定实算：格 76.86×70.52mm（按「小格中心→田字格右上角」反推，偏差 x%）`、
以及逐笔的起终点。

## 四、请你逐项确认（打勾）

- [ ] **1. 航点命名**：`paper{1-4}_{tl,tr,bl,br}` + `paper{i}_cell00_tl`（第 0 格左上**小格中心**）
      + `paper{i}_cell00_corner_tr`（该田字格**右上角**）。命名/语义与你们现场采集一致吗？
      ⚠️ 语义若不同，格距会算错 1.5 倍（我第一版就踩了），代码里两种解释都试并打印选了哪种。
- [ ] **2. 第 4 角容差 5mm**：`CORNER_TOL_MM`。纸本身有裁切误差的话可能要放到 8mm。
- [ ] **3. 高度/速度**：`RETRACT_MM=5`（笔画间抬笔）、`SAFE_HOP_MM=50`（进出字）、
      `WRITE_VEL=3`、`DESCEND_VEL=5`、`TRANSIT_VEL=10`。是否符合你定的 `写字≤5 / 转场≤10`？
- [ ] **4. 升降一律 `move_ik`**：落笔/抬笔/进字抬高都用 `move_ik`，水平走笔用 `move_to`，
      撞奇异点（99/112）自动转 `move_ik`，两个都失败才抛 `RuntimeError`。
- [ ] **5. 落笔下压 `PRESS_MM = 0`**：默认笔尖刚好触到示教纸面。现场按墨色调（淡→0.3，晕→0.1）。
- [ ] **6. 单体字白名单 45 个**（日月山水火田…）。多部件字要写必须显式 `--allow-complex`，
      且**先离线看 `plan_char` 的字形**。
- [ ] **7. 字形占格 80%**（`stroke_lib.GLYPH_FILL`）：实测最挤的「家」中心线距格线 6.8mm，
      加笔宽仍在格内。规则：**超出田字格边框 = 该字 0 分**。想改要连 `CACHE_VERSION` 一起 +1 重建缓存。
- [ ] **8. 工具坐标系**：`check_ready()` 会打印 `tool/wobj`，请确认和你标定时用的号一致
      （重启控制柜会重置）。
- [ ] **9. 越界检查**：所有格必须落在纸内（留 10mm 容差），否则直接报错，不会带着错格距去写。
- [ ] **10. 单客户端**：CNDE 只允许一个连接，跑本模块时别开别的脚本。

## 五、已知未做（需要主程序补齐，我不敢替你决定）

1. **蘸墨节奏没接**：`ink_pre` / `ink_dip` 航点已有，但 write_engine 只写字不蘸墨。
   建议按「累计笔长」触发（一个字 1 笔也有 10 笔，按字算墨量会不够）。
   ⚠️ `dip.every_strokes` 必须**实测**：一次蘸墨能连续写多少笔/多少 mm。
2. **300s 时间熔断没有**：`plan_char()` 会返回每字的 `total_mm`，主程序据此估算剩余时间，
   低于阈值（建议留 45s）就停手抬笔。现在 write_engine 不会自己停。
3. **纸 2/3/4 没标定**：现在只有 paper1 有 `cell00_*`，其余三张走官方图纸实测值兜底并打印告警。
   **纸一摆歪整体就偏**，建议每张都补采两个标定点。
4. **多部件字**（家/座/枝等）字形已能生成，但没做部件间避让/收敛，先别上真机。
5. **笔尖偏置**：默认认为示教纸面 z 就是笔尖触纸高度；若换笔/限位环有差异，要重新采点或加偏置常量。
